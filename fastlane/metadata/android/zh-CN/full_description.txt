cmux Pocket 是一款专为 macOS 平台 cmux 打造的开源独立 Android 伴侣应用，提供实时终端流式传输、沉浸式移动端视图以及基于安全网关的一键扫码配对。

核心特性

• 实时终端流式传输：通过安全的 WebSocket (wss://) 渲染 Mac 端的终端网格。PTY 与 VT 解析由 Mac 端负责，Android 不运行本地 shell。
• 双端解耦独立导航：在手机端自由切换工作区与标签页，完全不干扰 Mac 端的活动焦点。
• 手机宽度重排模式：支持请求 Mac 主机调整共享 PTY 宽度，使终端 TUI 界面适配手机屏幕宽度，亦可一键恢复。
• 一键扫码配对：通过 Mac 终端执行 `cmux-pocket qr` 生成配对二维码，手机相机扫码即可极速导入连接配置。
• 远程唤醒：当后台网关在线但 cmux 未运行时，支持在手机端直接远程唤醒 Mac 上的 cmux。
• 沉浸式终端界面：全屏终端画布、浮岛面包屑指示器、双指缩放、以及包含 ESC、Tab、Ctrl+C、方向键等终端常用键的辅助键盘栏。
• 画中画悬浮窗：支持以 Android 画中画悬浮窗形式在后台多任务中持续监控终端会话。
• 双语支持：内置完整的英文与简体中文界面，可在应用内自由切换。

工作原理

cmux Pocket 采用 Local-First 本地优先架构：
1. cmux (macOS)：运行真实终端实例并管理进程与终端状态。
2. cmux-pocket 网关 (macOS)：轻量级 Rust 后台服务，严格监听 127.0.0.1:8088，通过 UNIX Domain Socket 与 cmux 通信并通过 WebSocket 提供流传输。
3. 安全网络边界：通过 Tailscale HTTPS (.ts.net)、局域网反向代理 (Caddy/Nginx) 或 USB 反向代理连接，保障传输安全。
4. cmux Pocket (Android)：使用内置 Maple Mono Nerd Font 渲染终端网格单元格。

隐私与安全

• 100% 自由开源软件 (AGPL-3.0)。
• 本地优先，零遥测、零数据分析，无厂商托管的后端服务。由你选择连接 Mac 的网络方式。
• 网关严格绑定本地环回地址 (127.0.0.1)，通过随机 Bearer Token 鉴权。
• 连接配置与访问凭据使用 Android Keystore 保护的加密存储。
• 相机权限仅用于本地扫描连接二维码，不上传任何图像数据。
